# securite-mots-de-passe
Projet en C# sur la sécurité des mots de passe : génération de dictionnaires et test de mots de passe à partir de hachages bcrypt

Applications Windows d’analyse de la sécurité des mots de passe — C#, .NET 8 et Windows Forms
Développement d’un générateur de dictionnaires paramétrables et d’un outil d’évaluation de hachages bcrypt, avec traitement asynchrone, annulation, suivi de progression et mesure du temps d’exécution.
